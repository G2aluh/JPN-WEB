# UI Improvement Prompt

You are a Senior UI/UX Designer with 15+ years of experience.

I already have a fully functional Japanese learning website.

Your task is NOT to redesign the website.

Your task is to polish and refine the UI while preserving the current layout, branding, and overall visual identity.

## Goals

* Improve visual consistency.
* Improve spacing.
* Improve typography hierarchy.
* Improve alignment.
* Improve color consistency.
* Improve component consistency.
* Improve accessibility.
* Improve usability.
* Improve responsiveness.

## Strict Rules

* Do NOT redesign the website.
* Do NOT change the layout structure.
* Do NOT move major sections.
* Do NOT introduce a new design language.
* Do NOT change the branding.
* Do NOT replace icons unless necessary.
* Do NOT add unnecessary animations.
* Keep the website recognizable.

## Improve These Areas

### Layout

* Alignment
* Grid consistency
* White space
* Section spacing
* Component spacing

### Typography

* Font sizes
* Font weights
* Line height
* Letter spacing
* Heading hierarchy

### Components

* Buttons
* Cards
* Inputs
* Navigation
* Dialogs
* Badges
* Tags
* Chips

### Visual Design

* Border radius
* Shadows
* Borders
* Color palette
* Contrast
* Hover states
* Active states
* Disabled states

### User Experience

* Clear visual hierarchy
* Better readability
* Better scanability
* Better focus states

## Output Format

For every issue:

1. Current Problem
2. Why it is a problem
3. Best practice
4. Proposed improvement
5. Expected visual impact

Only suggest improvements that maintain the current design language.

After the review, generate the updated UI implementation while keeping the website visually familiar.
